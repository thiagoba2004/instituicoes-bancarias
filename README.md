# Instituições Bancárias

**Código canônico:** `PRJ-000022`  
**Projeto de Governança:** em inicialização pelo `PRJ-000002 — Gerador de Agents` (Rota A).  
**Visibilidade do repositório:** pública, confirmada no GitHub em 10/10/2026.

## Estado atual

Este repositório está sendo estruturado como Projeto independente de documentação e trabalho sobre **instituições bancárias**. O **objetivo substantivo, público-alvo, metodologia, entregas e eventual site público estão pendentes de definição expressa** pelo responsável. O título não autoriza, por si, implementar cursos, oferecer serviços ou alegar vínculo com instituições reais.

O código `PRJ-000022` é reservado e permanente. A estrutura de governança inicial seguirá o Kernel v1.11 do Gerador de Agents.

## Limites

- Repositório público não é cofre: não incluir dados pessoais privados, documentação sigilosa, credenciais, dados bancários de clientes ou documentos educacionais individualizados.
- Nenhuma afiliação institucional, certificação, autorização regulatória, prestação de serviço, pesquisa concluída ou site ativo foi comprovado.
- Novas entregas dependem da missão aprovada, do `PROJECT_STATE.json`, dos Planos de Fases e dos registros do Projeto.
